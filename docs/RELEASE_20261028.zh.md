## 使用哪份插件

生产内核提交为 `8482cf744aaae566ab1b65fb09fe63415219b67a`；随后仅合入 benchmark、诊断入口和文档。
本目录下不可变验证插件位于：

```
build/shared-online-20261028/plugins/weave/fix_crystallize_plugin.so
build/shared-online-20261028/plugins/kokkos/fix_crystallize_plugin.so
build/shared-online-20261028/plugins/host/fix_crystallize_plugin.so
```

它们是 WSL x86-64/SM89 构建，不能拷到 ARM64 A100 上直接运行。

不要根据同名旧 `.so` 或旧目录名推断当前版本。

WSL 运行时使用宿主 `Al3Sc-kokkos-joint-20261027/lammps-build` 和
`Al3Sc-kokkos-shared-20261028/weave-build`；参数例子见
[集成指南](../benchmarks/integration/README.md)。Weave 必须在创建 box 前加载并调用 weave/batch_comm。
CUDA-aware MPI 的 sanitizer 诊断可通过该指南中的 early_cuda.py 显式选择设备。

## 仍有边界

CSS、LocalQL、Q 和 LocalGeom 可联动 Kokkos 的设备邻居与 GPU 计算；这不等同全项目零 Host。
选择集/标签等元数据、LocalQL 纯 J 标量计数、全局规约及显式诊断仍存在 Host 路径。
无 Weave 的原生 Fix reverse 暂存边界包；DISTANCE 有标量 Host 几何/通信；ML/ONNX 本轮关闭。
MPI 内部传输是否使用 Host 暂存取决于实现与配置，本轮 TCP 验收未证明 RDMA 性能。

共享在线表目前是一维非周期 family 表，沉积步计算量 O(N×节点数)，历史每次存整张表。
动态组改变物理定义、海量中心沉积成本和历史文件规模需要各自的输入约束与容量评估。
全局空 family 拒绝；非空 family 中的无中心 rank 已验证。

控制模型的冻结重加权通过，不代表真实 Al3Sc 的形核机制、联合 FES、时间依赖重加权或
物理速率已完成科学验收。20 ps 的稳定轨迹只支持其实际覆盖的工程结论。
