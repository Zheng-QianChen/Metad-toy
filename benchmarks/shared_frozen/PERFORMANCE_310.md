单次小幅快慢不能证明稳定优势；应结合重复范围判断。冻结共享表在 GPU 中批量处理中心，
不会为每个中心分别启动一张图。两条路径共用 LocalQ6/CSS 的近邻计算和力回传。
当前测量将这些成本合在 Modify 中，不能进一步定量区分 CV kernel、查表、拷贝和等待。

以 Kokkos 单 rank 的共享方案为例，新增完整步时为 6.3034 ms/步；Modify 分项增量约 4.3826 ms/步，Neigh 分项增量约 1.9300 ms/步。各分项独立取中位数，因此不要求精确相加等于总差值。更细的 kernel、拷贝与等待占比需要另做 profiler 测量。

## 运行条件

- 310 直接运行，未使用 Slurm。RTX 4090 D；CPU Intel Xeon Platinum 8163，96 逻辑核。
- LAMMPS 29 Aug 2024、Kokkos 4.3.1、CUDA 12.2，Release；Kokkos debug 与 UVM 关闭。
- 每个 rank 的 OMP_NUM_THREADS=1。两 rank 配置共用一张 GPU，GPU-aware MPI 关闭。
- 6912 原子，1728 Sc。相同 restart、MEAM 文件及 LocalQ6×CSS 径向参数。
- NPT 1450 K / 1 bar，dt=1 fs，温控阻尼0.1 ps、压控阻尼1 ps。每步计算所需 virial。
- neighbor skin=2 Å，comm cutoff=12 Å，check yes，每5步尝试排序；各组保持一致。
- 无轨迹输出，thermo 仅记录各 run 起止状态。原生产任务和安装均未改动。
- 每个独立进程预热50步；预跑50步用于选取同组正式步数；随机交错执行三轮。
- 取第二段 LAMMPS Loop time，排除进程启动、NVRTC 编译、读表、建图和预热。
- 每次运行前后均未发现其他 GPU 计算进程；节点不是独占预约，不能排除 CPU 系统噪声。

- MEAM/CPU，1 rank：每轮正式 200 步，三种路径均相同。
- MEAM/CPU，2 ranks：每轮正式 200 步，三种路径均相同。
- MEAM/kk，1 rank：每轮正式 300 步，三种路径均相同。
- MEAM/kk，2 ranks：每轮正式 200 步，三种路径均相同。

NVRTC 三轮实测范围 154.78–160.91 ms，单次运行只在启动编译一次。

## 偏势与适用范围

公共描述符为 s_i=q_i*c_i*fermi(q_i*c_i,0.35,15)。
原有 Global Graph 对 Sc 求 AVE(s)，使用4096点网格及一个非零冻结 Gaussian hill
（center=0.058、height=0.02 eV、sigma=0.05）；
共享路径对每个 Sc 查同一张141点表 u(s)=0.4*(s−0.35)^2 eV，再取 MEAN(u(s))。
两者初始 AVE(s) 一致到1e-15，偏置力均参与计算。

两种势的数学形式不同；本轮比较计算成本，未评价 FES 质量或采样效率。
PACE=0，因此没有测量动态沉积、历史同步或大历史重启成本。
结论限于该体系规模、参数和单卡；两 rank 的结果不能外推为多 GPU 或多节点结果。
