# Al3Sc LocalQL × CSS：暂停生产任务后的对照

2026-10-22，用户授权后暂停生产调度器及其 LAMMPS 子进程，重复同一组测试。
当前版总步时中位数 **63.3214 ms**，比生产旧版减少 **3.46%**，
比上传版减少 **1.26%**。生产任务在测试结束后自动恢复，暂停约 **5.85 分钟**。

生产任务暂停后资源竞争减少，版本排序与上一轮一致；系统负载和频率仍可能影响小幅差距。

## 数值、工作量及恢复检查

- 9 次运行均结束于第 6220600 步，每次计时段重建邻居表 17 次、新增 3 个 WT hill。
- 全部 thermo 采样点的 CV 最大差为 3.235e-11，偏置能最大差 4.151e-08 eV。
- 偏置压力最大差 1.331e-05 bar；hill 中心最大差 3.235e-11，高度最大差 9.132e-12 eV。
- 以上均与同轮生产旧插件比较，通过与上一轮相同的容差。初态逐原子核对复用上一轮同一冻结资产的结果。
- 每次计时前后的进程快照均确认生产 worker 和 LAMMPS 子进程处于暂停状态。
- 守护程序正常完成，返回码 0，通过 finally 恢复两个进程；备用 watchdog 未触发。
- 跨过此次暂停的生产分段墙钟会包含暂停时间，复查该段速度时需扣除记录的暂停时长。

## 范围与材料

体系为 6912 原子（Sc 1728）、1 rank、MEAM＋NPT 1450 K/1 bar、1 fs、WT factor 50、PACE 200。
表达式为 `AVE(q*c*fermi(q*c,0.35,15))`，q 为原始 LocalQ6，c 为 CSS。
完整参数和插件 hash 见[上一轮报告](AL3SC_PRODUCTION.md)。本次仅新增基准记录与文档。
结果适用于本机、这个初态与这组参数；未覆盖多 rank、其他 GPU 或每 10000 步的生产轨迹写盘/分段重启。
